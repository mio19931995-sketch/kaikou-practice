# Agnes 多维表达教练（0.7.0）

规则实现：server/agnes.mjs，版本 agnes-coach-1。仅对 Agnes 官方接口启用新点评契约，其他服务保持原有协议。

依据：题目、转写、选定结构、训练场景，以及复述原文（如提供）。开放题没有唯一标准答案；应用给出场景检查标准和需要填写真实信息的表达框架，不生成虚构的事实答案。

六个维度：切题与重点、结构与逻辑、事实具体程度、听众与沟通目的、文字清晰简洁、结论与下一步。汇报替换为影响协作和行动负责人时间；面试检查个人贡献和结果经验；说服关注对方顾虑；复述对照主旨、关键事实和忠实度。

每项返回：已做到／需完善／未体现／需确认、逐字原话、具体分析、改进方法。另给1到2个优先任务。参考表达框架由应用提供，方括号必须补充真实信息。

服务端检查六项ID与顺序、枚举、长度、引用必须在转写中出现，并拦截已知提示词复述模式。失败显示分析未完成，不伪装为基础反馈。此校验不保证语义判断完全正确，也不能全面检测所有指令复述。

当前没有音频声学分析，不评价发音、情绪、语调、停顿。只完成一条汇报样例的真实测试，其余场景须继续积累真实样本验证。
