# 设计依据


0.1 版采用手机网页。0.2 版按用户新要求改为独立 Windows 应用，桌面窗口最小 1080×720，初始 1420×960，同时保留浏览器版小屏布局。

用户指定的是“适合表达训练软件调性的 UI”，未要求复刻 Lulu 的特定视觉。桌面版使用安静、清爽的草木绿和浅灰工作台，强调持续练习，不增加虚构数据和无实际作用的控件。

- 固定左侧栏：练习概览、即兴表达、逻辑表达、复述素材、21 天计划和历史记录。
- 工作台：宽屏欢迎区域、三种练习卡片、素材建议、今日目标、最近七天和历史摘要。所有进度来源于本机真实练习。
- 训练：深蓝专注区，左侧完成题目、录音与反馈操作，右侧展示对应表达结构和提醒。
- 逻辑框架：左侧选择、右侧教学案例；素材库使用多列卡片；课程按周横向展开；记录使用宽屏行式布局。
- Windows：使用真实系统标题栏和窗口控制，不伪造浏览器中的关闭/最小化按钮。自有声波图标用于窗口、快捷方式和安装包。

原始移动界面继续沿用浅色首页与深蓝训练页，在小于 1000px 的浏览器视口显示；桌面布局从 1000px 起启用。

UI/UX Pro Max 的移动交互规则用于触控、焦点、错误提示、固定栏间距、减少动画和多尺寸检查。其自动设计查询返回了偏营销/游戏化的风格和字体，与参考视频不符，因此未采用推荐的活动报名布局和科幻字体；配色和信息结构以用户视频为准。

- 浅色：背景 `#f7f8f4`，文字 `#1c2923`，深绿 `#336744`。
- 深色：背景 `#101c38`，文字 `#f0f4fc`，次要文字 `#a0afc6`。
- 主动作：`#b6f785`，深绿色文字。
- 字体：本机系统中文无衬线字体，不依赖外部字体请求。
- 图标：Phosphor 统一线性图标；功能卡采用同一图标的双色变体。
- 主按钮至少 50px，普通交互至少 44px；移动底栏预留安全区。
- 真实音量驱动录音波形；只有倒计时和请求等待使用必要动画；支持减少动态效果。
- 数据均从真实保存的练习计算，无预填练习记录、虚假评分或伪造 AI 输出。

## 场景表达（0.3.0）
逻辑表达默认以真实任务组织：工作汇报细分为进度同步、成果汇报、向上求助，另有建议、面试、观点、知识解释、复盘、日常沟通和故事分享。每项任务给出首选结构与一个有条件的备选，展示完整示例，并将场景题目和所选结构带入练习。结构库保留直接学习入口。新增七种原创练习模板，不将其包装为标准化模型。


## 软件内模型配置（0.3.1）
移除打开 env 文件入口。设置页增加服务预设、可编辑地址和模型、隐藏密钥输入、连接测试、保存即时生效及停用入口。测试不保存草稿，保存不伪称已测试通过。密钥不回显，换地址必须重新输入；通过受限 Electron IPC 处理，使用 Windows 本机加密保存。


## Windows 重定向目录保存修复（0.3.2）
在真实 APPDATA 路径复现同目录 rename 返回 EXDEV。保存增加加密文件复制兼容路径，普通复制失败时恢复上一份内容；首次保存遗留的完整加密临时配置可在启动时恢复。测试覆盖模拟 EXDEV、失败恢复、首次保存恢复，以及真实 APPDATA 下的 Electron 保存／重启／清除流程。错误提示按空间、权限、占用分别说明。


## 自动语音转文字（0.4.0）
修复空文字导致点评按钮无反馈的问题，录音下方显示转写状态和可编辑文本。桌面启动检查本机 Python/faster-whisper/small 缓存，识别进程隐藏窗口，通过标准输入传递音频，不写临时录音文件；5 分钟超时并限制单任务并发，失败可重试。当前机器实测中文语音识别成功，Agnes 真实点评请求返回 source=ai。本机识别依赖本机现有运行环境与模型，安装包未内置这些大型依赖。


## 点评入口与历史记录续练（0.4.1）
录音回顾页底部固定展示点评与保存操作，避免长文本将主按钮推到屏幕之外。历史记录详情新增音频转写、文本编辑、保存文字和生成／重新生成点评；更新原记录，不创建重复练习，不更改原录音和日期。修改草稿离开前确认，处理时禁用删除，失败保留文字。


## AI 配置状态刷新（0.4.2）
每次检查状态和提交请求前重新读取已保存的加密配置；前端在窗口重新获得焦点及定时更新服务状态。配置读取错误返回明确失败，不降级为基础反馈。测试覆盖启动后配置变化、生成真实 AI 来源以及读取失败路径。


Agnes 实测返回包含未转义引用的 JSON 时，先做格式修复，再按完整报告结构校验；截断输出和缺失必需字段仍报错，不补造点评。JSON 强制模式在此模型实测出现截断，最终继续使用普通对话输出配合格式校验。已用现有加密配置实测返回 HTTP 200、source=ai。
