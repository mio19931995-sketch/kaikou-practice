# 0.10.0：点评后知道怎么练，失败后可以继续

本轮实施最高优先级的练习闭环与 AI 失败恢复，保留现有独立思维框架板块。

## 使用流程

1. 录音转写或填写文字后，生成点评。系统先保存练习，再请求模型。
2. 在“这次先改一个地方”中，从最多两项建议里选一个重点，点击“针对这一点再练”。
3. 进入同一道题，保留原来的框架、复述材料、点评场景和时长设置，重新表达。新练习单独保存，上次记录不被覆盖。
4. 新点评展示两次模型判断与对应原话。桌面左右对照，手机上下阅读，详细维度可展开。
5. 从“我的练习”也能继续同题练习。未点评的记录亦可同题重练。

## 比较边界

- Agnes 与 Jev 场景点评均支持已有结构化结果的比较；通用模型缺少对应标准时只展示文字对照。
- 模型、规则版本、场景或 Agnes 维度标准不同，不直接比较判断。
- 判断变化不换算成进步分数，不据文字推断语调、声音或已经掌握。
- 保留修改原文字后重评的旧功能；与重新录音的独立记录流程分别标注。
- 框架入口和原始任务保持一致；找不到上次记录时明确提示，不能偷偷换成随机题。

## 失败恢复

- 显示等待时长，不编造模型内部进度或完成百分比。
- 网络、超时、授权、繁忙及返回内容校验失败提供对应提示。
- 失败后可点击“重试 AI 点评”，不需要重新录音。不会自动循环消耗调用额度。
- 历史记录中编辑的文字也会在分析前保存；失败后重启仍可继续。
- 本机存储失败时不假报保存成功，也不继续发出分析请求。
- 若 AI 已返回而点评写入失败，页面保留该结果，可直接重试保存，不必再次调用模型。
- 开放题规则明确允许不同合理表达，不把与参考模板措辞不同当作信息缺失。
- 实测发现 Agnes 有时遗漏逐维建议：允许该可选字段缺省，展示已有分析和总体练习建议，不编造缺失内容。
- 原话证据改为让模型选择原文片段编号，应用还原原话；无效编号和伪造引用仍被拒绝。保留对旧格式逐字引用的校验兼容。规则版本更新为 agnes-coach-2，因此旧规则点评不会直接标为同标准进步。

## 验证记录

32 项服务端/规则/设置测试通过。新闭环、既有录音与历史点评、Agnes、Jev、桌面导航和布局相关测试通过；包含手机与桌面的同题往返、重启、两条记录分别保存、模型变化停止比较，以及失败不丢失编辑文字。额外模拟点评写入失败，验证无需再次调用模型即可保存已收到的结果。

框架选择助手、理解小测与完整首次使用引导未纳入本轮。它们仍可作为下一阶段，避免同时改动过多入口。

桌面验证：独立窗口、录音回放、保存后重启检查通过；最终 0.10.0 桌面已打开，原 AI 与本地语音转写配置均启用。实际桌面服务的 Agnes SBI 请求返回 HTTP 200 和六维点评。单次成功不代表外部模型永不失败，重试和内容保留流程仍然必要。
